# LexiNote — Словарь иностранных слов

Учебный проект по практике УП.01 (ГБПОУ НСО «Новосибирский строительно-монтажный колледж»).

**Автор:** Астанаева Полина Сергеевна, группа ИСП 24.1.  
**Тема № 27:** Словарь иностранных слов.

## Технологический стек

- **Фреймворк:** Next.js (App Router)
- **Язык:** TypeScript
- **Стили:** Tailwind CSS
- **База данных:** SQLite (`prisma/dev.db`)
- **ORM:** Prisma
- **Валидация:** Zod

## Основные возможности

- Просмотр списка иностранных слов с транскрипцией, переводом и примерами.
- Поиск в реальном времени по слову и переводу.
- Фильтрация по тематическим категориям и статусу изученности («Новое», «Изучается», «Выучено»).
- Добавление, редактирование и удаление карточек слов (доступно после входа).

## Инструкция по запуску

1. **Клонируйте репозиторий:**
   - Откройте VS Code, нажмите `Ctrl + Shift + P` (или `F1`), введите `Git: Clone` и вставьте ссылку:
     ```text
     https://github.com/astanaevapolina-ship-it/foreign-dictionary.git
     ```
   - Выберите папку для сохранения, откройте скачанный проект в VS Code и переключитесь на ветку `develop` (в левом нижнем углу окна VS Code нажмите на текущую ветку и выберите `origin/develop`).
   
   *Или выполните во встроенном терминале VS Code (`Ctrl + ~`):*
   ```bash
   git clone -b develop https://github.com/astanaevapolina-ship-it/foreign-dictionary.git
   cd foreign-dictionary
   ```

2. **Откройте встроенный терминал VS Code** (`Ctrl + ~` или через верхнее меню: `Terminal` → `New Terminal`) и установите зависимости:
   ```bash
   npm install
   ```

3. **Создайте файл переменных окружения** на основе шаблона (если файл `.env` отсутствует):
   - В панели проводника VS Code (слева) скопируйте файл `.env.example` и переименуйте копию в `.env`, либо выполните в терминале VS Code:
   ```bash
   copy .env.example .env
   ```

4. **Инициализируйте базу данных SQLite и наполните её тестовыми словами:**
   ```bash
   npx prisma migrate dev --name init
   npm run db:seed
   ```

5. **Запустите сервер разработки:**
   ```bash
   npm run dev
   ```

6. **Откройте приложение в браузере:**
   - Зажмите `Ctrl` и кликните по ссылке `http://localhost:3000`.
